# Quiz 8 - Design Research for Major Assignment


## Part 1: Imaging Technique Inspiration

I am inspired by Van Gogh’s *The Starry Night* as my imaging technique. I want to adopt its swirling curved brushstrokes, flowing nebula texture and strong blue-yellow colour contrast. The soft, twisting circular lines create a dreamy, dynamic moving atmosphere. Incorporating this fluid, distorted visual style fits the assignment well, as it allows me to use generative code to recreate organic, flowing abstract motion and expressive colour gradients.

## Part 2: Coding Technique Exploration

The coding technique I use is **Perlin Noise (`noise()`) + particle flow + polar coordinate distortion** in p5.js. Perlin Noise generates smooth, random curves that mimic Van Gogh’s swirling brushstrokes. Particle systems create the twinkling stars and flowing nebula. Polar distortion bends lines into circular vortexes, recreating the dynamic, dreamy rotation of *The Starry Night*. These tools together turn static colours into moving, organic patterns.
